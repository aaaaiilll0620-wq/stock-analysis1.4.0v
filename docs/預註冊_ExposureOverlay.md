## 2. 假設(凍結門檻;在看到 A×C 的 OOS 數字之前寫死)

### HO1 — 部署門檻(主假設)
A×C 的 **walk-forward OOS**(同 A 的 H2 OOS 段,2010-01~2026-03)同時滿足:
- **OOS MDD ≥ −40%**(即回撤不低於 −40%;使用者 2026-07-30 拍板的正式部署門檻),**且**
- **扣成本 OOS CAGR ≥ 20%**(overlay 不得把報酬壓到本體的 pass 線下)。

> MDD 一律指 §3-A(f) 定義的 OOS 淨值最大回撤;以 `|MDD|`(正 %)表回撤幅度。

> HO2、HO3 皆在**主測日限速路徑**(§3-A-D:`e_lim(d)`、日 `r_A(d)`)上進行;§3-A-M 月頻結果同表並報作對照。

### HO2 — 擇時 vs 純減碼(**核心科學問題**,Codex 關切;**確定性,無隨機**)
**比較對象**:常數曝險對照 `A×ē`,`ē = (1/D)·Σ_d e_lim(d)`(日主測平均曝險),
`r_flat(d) = ē·r_A(d) + (1−ē)·r_cash_d − |ē−e_prev(d)|·0.285`,`e_prev(1)=1.0`
(僅首日扣 `|ē−1|·0.285`,其後 0)。
**比較量**:`dd_AC = |MDD(r_AC)|`、`dd_flat = |MDD(r_flat)|`(日 NAV,§3-A-D)。
**通過條件(全部確定性,無 seed)**:
- `dd_flat − dd_AC ≥ 5.0 pp`(A×C 回撤比同均曝常數線淺至少 5pp),**且**
- `CAGR(r_AC) ≥ CAGR(r_flat) − 1.0 pp`(相同平均曝險下,擇時不得以犧牲報酬換取較淺回撤)。
> 常數 `ē` 平均持倉相同且 `TV≈0`(幾乎不付換手成本)→ 對 A×C **成本上保守**:A×C 反而多付換手,
> 若仍淺 ≥5pp,擇時證據更強。HO2 測「擇時 vs 完全不擇時」;TV 對齊由 HO3 負責。

### HO3 — **相位對齊虛無(Phase-Alignment Null)**(固定曝險/成本路徑,只旋轉報酬相位)
> **命名與主張範圍**:本檢定名為「相位對齊虛無」。它只問一件事 ——「**固定的曝險排程與實際報酬的
> 相位對齊,是否比同一排程對上被旋轉的報酬更能壓低回撤**」。**不主張**這是一般性的「隨機擇時」檢定:
> 它未隨機化曝險排程本身、未涵蓋其他可能的曝險路徑,只檢定 `e_lim` 與 `r_A` 的**對齊相位**。
> 前一版用「旋轉 `e_lim` + 循環 K/TV 計法」被否決:循環計法與 §3-A-D 部署公式的
> `e_lim(0)=1.0`、**線性**每日換手成本不一致 → 在部署慣例下成本並非完全相同。
> 本版改採「**固定 `e_lim` 與其成本路徑,只旋轉 `r_A(d)`**」,使成本在**與部署完全相同的
> 線性邊界與初始曝險**下逐日元一致。

**虛無建構**:保持主測日限速曝險路徑 `e_lim(1..D)`(含 `e_lim(0)=1.0`)**完全不動**,
僅對本體日報酬做**循環旋轉**:`r_A^τ(d) = r_A( ((d−1+τ) mod D) + 1 )`。null 淨報酬用
**與 §3-A-D 逐字相同**的公式:
```
r_AC^τ(d) = e_lim(d)·r_A^τ(d) + (1−e_lim(d))·r_cash_d − |e_lim(d)−e_lim(d−1)|·0.285
```

**嚴格不變量(由建構,非近似)**:
| 量 | 為何不變 |
|---|---|
| overlay 換手成本 `Σ_{d=1}^{D} |e_lim(d)−e_lim(d−1)|·0.285` | 純 `e_lim` 的函數;`e_lim` 一位元未動 |
| `ē`、`K`、`TV=Σ|Δe_lim|` | 同上,皆 `e_lim` 的函數 |
| 現金貢獻 `Σ(1−e_lim(d))·r_cash_d` | `r_cash` 常數、`e_lim` 固定 |
| 本體毛報酬 `Π_d(1+r_A(d)/100)` | 旋轉是相同日報酬多重集的重排,連乘可交換 → 全期毛報酬**恆等** |
| **邊界** `e_lim(0)=1.0`、線性每日成本 | 與部署 §3-A-D **完全相同**;首日成本 `|e_lim(1)−1|·0.285` 對實際與所有 null 皆同 |

**唯一變因**:固定曝險排程與(旋轉後)報酬的**對齊相位** → 純粹檢定**相位對齊**(非一般隨機擇時)。

**邊界處理**:`r_A` 的旋轉為 D 日 OOS 窗內的循環位移;唯一接縫是 day D→day 1 這對(標準循環虛無接縫),
本體日報酬多重集不變故全期毛報酬恆等。曝險側**無**接縫(`e_lim` 不旋轉,線性邊界原樣保留)。
觀測統計量取 τ=0(恆等),與 null 用同一公式、同一邊界計分 → 完全可比。

- **RNG**:`numpy.random.default_rng(20260730)`(固定)。**reps `B=1000`**:τ 自 `{1,…,D−1}`
  以 `rng.integers(1, D)` 均勻抽取(可重複)。
- 每個 `r_A^τ` 算 `r_AC^τ` → `dd*_τ=|MDD|`(日 NAV,§3-A-D)。
- **統計量/方向(單尾加一)**:`dd_real=|MDD(r_AC)|`,`p=(1+#{τ:dd*_τ ≤ dd_real})/(B+1)`,
  方向「實際較淺」。**通過:`p<0.05`**。
> overlay 總換手成本在實際與每一條 null **逐位元相同**(成本只依 `e_lim`)→ 徹底排除
> 「隨機組成本不同」的 confound,且不引入任何非部署的邊界慣例。

## 3. 量測協定(凍結)

### 3-A 精確公式(報酬皆為 %;`RF_ANNUAL=1.0`、`DERISK_COST=0.285` 取自碼)

共用:`e_daily` = 三條 MA(50/100/200)各自 `debounce(up=3, down=3)` 後 above 狀態(0/1)平均
→ `e_daily ∈ {0, 1/3, 2/3, 1}`(`ladder_expo_daily`)。overlay 換手成本一律 `|Δe|·0.285`
(每單位曝險變動;與 A 的 0.72% 選股換手分開,日/月同一單位成本)。

**§3-A-D 每日限速路徑(部署模擬主測)** — 交易日 `d = 1..D`(OOS 全期日序列):
- **訊號** `sig(d)` = `e_daily(d)`:由等權市場指數 vs MA50/100/200 + debounce(3/3)算出,**只用到 close(d) 為止**的收盤,於 **close(d)** 才確定(§3-A-D-⏱)。
- **限速曝險** `e_lim(d)`(持有 open(d)→open(d+1) 這段時的曝險):速率限制器朝**前一收盤的訊號**走位 ——
  `e_lim(d) = e_lim(d−1) + clip(sig(d−1) − e_lim(d−1), −0.20, +0.20)`,`e_lim(0)=1.0`、`sig(0)=1.0`,
  `cap=RATE_LIMIT_CAP=0.20`。**用 `sig(d−1)` 不用 `sig(d)`,即無 look-ahead**(§3-A-D-⏱)。
  **自 OOS 起點即套用**(執行實境反事實;非生產 2026-08-05 gate)。
- **現金腿(日)**:`r_cash_d = RF_ANNUAL/252`。
- **A 日報酬** `r_A(d)`(**來源已釘定**):
  - **價格源**:`{TEJ_CACHE}/price_valuation/*.parquet`(與 `scripts/build_exec_ret.py` 同一日價線;
    欄位 `open/close/dividend_yield_TSE`)。**不另立價源**。
  - **持股時點**:每月的雙確認 ∩ 名單,等權建倉於 **open(訊號日+1)**(fwd_x 慣例);
    **月內買進持有(權重隨價漂移,月內不重新平衡、不換股)**,僅在下月訊號日+1 依新名單重配。
  - **日報酬(價格 + 均勻加性股利,見 §3-A-D-💰)**:`r_A(d) = Σ_i w_i(d−1)·r_i(d)`,
    `r_i(d)` = 個股 i 的 **open(d)→open(d+1) 價格報酬 `pr_i(d)`** 加上**均勻每日加性股利** `δ_i(t)`;
    `w_i` 於建倉日等權、月內漂移。**不使用除息日現金流**(資料未提供、且會引入事後選日)。
  - **月聚合**:見 §3-A-D-💰。⚠ **注意兩個不同的陳述,不可混為一談**:
    (a)**加性分解**`(價格連乘−1)·100 + Σδ` 對 `fwd_x` **精確**(凍結門檻);
    (b)**實際日 NAV 複利** `Π_d(1+r_A(d)/100)` **不等於** `1+r_A(t)/100`(δ 被一起複利)——
    差異已實測並列為揭露項,**不得宣稱恆等**。
- **日淨報酬**:`r_AC(d) = e_lim(d)·r_A(d) + (1−e_lim(d))·r_cash_d − |e_lim(d)−e_lim(d−1)|·0.285`。
- **NAV/MDD**:`NAV(d)=Π_{s≤d}(1+r_AC(s)/100)`;**MDD 在日 NAV 上量**(捕捉**日頻觀測下**的谷底 ——
  以每日 open→open 段為觀測點,較月頻更嚴、更貼近部署真實回撤;**非** tick 級盤中最低點);`|MDD|` 為正 %。
  CAGR = `(NAV(D)/NAV(0))^(252/D)−1`。

**§3-A-D-⏱ 日訊號 / 日報酬時間對齊(無 look-ahead,凍結)**

三個時點嚴格分離,與 dual100 月頻慣例(close 算訊號、open+1 執行)一致,只是降到日頻:

| 時點 | 事件 | 只用到的資訊 |
|---|---|---|
| **close(t)** | 算訊號 `sig(t)`(等權市場 vs MA50/100/200 + debounce3/3) | ≤ `close(t)` 的收盤價 |
| **open(t+1)** | 執行:把曝險朝 `sig(t)` 走一步(限速 ≤0.20),付 `|Δe_lim|·0.285` | `sig(t)`(前一收盤已知) |
| **open(t+1)→open(t+2)** | 這段 open-to-open 報酬 `r_A(t+1)` 由 `e_lim(t+1)` 加權 | 與 `sig(t)` 對齊 |

**對應規則(凍結)**:報酬段 `r_A(d)=`〔open(d)→open(d+1)〕由 `e_lim(d)` 加權;而 `e_lim(d)` 只依
`sig(d−1)`(= close(d−1) 收盤才確定的訊號)→ **決定某段報酬曝險時,只用到該段進場 open 之前的收盤資訊**。

**訊號變更日範例(驗無 look-ahead)**:設等權指數在 **close(D)** 跌破 MA50、且滿足 3 日 debounce →
`sig(D)` 由 1 降到 2/3。
- 該降檔**只影響 open(D+1) 起**的曝險:`e_lim(D+1)` 從 1 朝 2/3 走一步(≤0.20/日),加權
  `r_A(D+1)=`〔open(D+1)→open(D+2)〕—— 這段報酬**在 close(D) 之後才發生**,訊號未用到它。✅
- **跨越訊號日的報酬段 `r_A(D)=`〔open(D)→open(D+1)〕仍由舊曝險 `e_lim(D)`(依 `sig(D−1)`)加權**,
  **不會被 close(D) 的新訊號回溯改權** → 訊號日當天的報酬沒有被「事後才知道的訊號」佔便宜。✅
- 若誤用 `sig(D)` 去加權 `r_A(D)`,就是拿 close(D) 的資訊賺 open(D)→open(D+1) 的報酬 = look-ahead;
  本規則以 `e_lim(d)←sig(d−1)` 由**建構**排除。

**§3-A-D-💰 股利分配規則(凍結;對齊 `build_exec_ret` 的加性 `dy12`,非除息日現金流)**

`build_exec_ret.py` 的官方 `fwd_x = (open_out/open_in − 1)·100 + dy12`,其中
`dy12 = clip(dividend_yield_TSE(as_of), 0, 15) / 12`(**年化殖利率的 1/12,加性**,取自 as_of 當日,
**非除息日現金流**)。故本案**不**用除息日現金流(資料未提供、且會引入事後選日)。**選定分配方式:均勻每日加性累積。**

- **定義**:月 `t` 的窗有 `n_t` 個 open→open 日段(取自交易日曆,建倉日即知);每日加性股利
  `δ_t = dy12_t / n_t`,加到該日價格報酬:`r_A(d) = pr(d) + δ_{t(d)}`。
**⚠ 兩個陳述必須分開,不是同一件事**(前一版誤寫成「由建構恆等」,已更正):

**(1) 加性分解 → 精確對帳 `fwd_x`(這是凍結門檻)**
月度以 `fwd_x` 自身的**加性**慣例聚合:
`(Π_{d∈t}(1+pr(d)/100) − 1)·100 + Σ_{d∈t} δ_t = (open_out/open_in − 1)·100 + dy12 = fwd_x`。
價格連乘 telescoping、股利加總 `Σδ = dy12` → **精確**。**已於完整 dual100 組合 × 正式 OOS 驗證**:

| 對帳 | 範圍 | 最大差 | >0.01pp |
|---|---|---|---|
| 單股 加性 vs `fwd_x` | 296,050 stock-month | **5.7e-13 pp** | 0 |
| **組合** 加性 vs 官方 gross | **OOS 194 月、~48 檔** | **9.4e-07 pp** | **0/194** |

→ **凍結門檻:此加性對帳殘差 >0.01pp 即擋凍結。**

**(2) 實際日 NAV 複利 → 不等於 `r_A(t)`,差異須實測並揭露**
日 NAV `Π_d(1+r_A(d)/100)` 會把 `δ` 一併複利,故**與加性的 `r_A(t)` 不相等**(cross-term ≈`(R−1)·dy12`)。
**已於完整 dual100 組合 × 正式 OOS(2010-01~2026-03,194 月)實測**(本體 A,無 overlay):

| 日股利模型 | 日NAV複利月報酬 vs `r_A(t)` 最大月差 | 中位 | >0.01pp |
|---|---|---|---|
| **均勻 `δ=dy12/n`(選定)** | **0.055 pp** | 0.0099 pp | 95/194 |

**判定:股利「分配到哪一天」對 MDD 的影響 ≤ 0.10pp**,相對 −40% 門檻(本體 A OOS 日 MDD −33.7%,
距門檻 6.3pp)僅佔約 **1.6%** → **遠小於門檻**,故**列為揭露項,不需重新定義日股利模型**。

**(3) 避免事後選日**:`δ_t = dy12_t/n_t` **均勻**;`dy12_t` 用 as_of 當日殖利率(訊號時點已知,
