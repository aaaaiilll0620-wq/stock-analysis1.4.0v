# 台股四維度決策系統 — 使用指南

> 這是一套**研究/篩選輔助工具**,幫你用一致、可回測的邏輯替個股評級與排序。
> **它不是投資建議**,也不會幫你下單。評級是對股票「當前狀態」的分類,不是「立刻買進」的指令。

> **⚖️ 先講最誠實的一句話(2026-07 校正)**:認真拿**含息還原的 0050 買進持有**當基準(2005–2026 年化約 14%、夏普 0.78)重跑後,
> 本系統的選股**在整個市場循環約略貼平至微贏 0050,不是印鈔機**。它真正的價值在**風控補回撤**(空頭少賠)與**選股研究/紀律練習**,
> 不在「報酬狂勝大盤」。**務實配置 = 核心用定期定額買 0050(賺長期複利)+ 一小部分衛星資金玩個股(練功/求穩)**。
> 頁面新增的「🚦 市場燈號 / 💰 定期定額 / ✨ 雙確認精選」三個分頁,就是把這個誠實結論做給你自己看、自己驗。

---

## 1. 這套能做什麼

- **個股分析**:輸入一檔代號,看它在四大維度 (基本面/估值/技術面·動能·籌碼) 的評分、最終評級、以及買點提示。
- **多檔排行**:一次評估多檔,依綜合分排序,快速看哪些強、哪些弱。
- **綜合分選股**:讀一份事先算好的分數快照,把**整份自選名單**一次拿來跨股排名 —— 0 API、免 token、瞬間出結果,適合大範圍海選。
- **全市場掃描**:0 API 從上市+上櫃約 1,900 檔自動海選,找 watchlist 之外的新標的(見第 9 節)。
- **市場燈號**:看「現在該持有幾成」(0/33/67/100% 曝險) —— 不預測漲跌,只反應趨勢/波動,是空頭少賠的風控紅綠燈(見第 10 節)。
- **定期定額試算**:輸入每月金額+起始年,並排看「策略 vs 0050」的實際到手報酬(MWRR)與回撤(見第 10 節)。
- **雙確認精選**:同時被「價值」與「品質」兩套邏輯看好的交集名單,附對含息 0050 的誠實回測(見第 10 節)。
- **實戰演練**:把選股名單當 30 天模擬單來練操作紀律(回填成交、追蹤 vs 0050、對帳),見第 10 節。
- **法人流向**:看三大法人的錢每天往**哪個產業**流(長條排行、可播放連續天數、產業地圖 Treemap、可下鑽到成分股)。
  **這是盤面描述圖,不是買賣訊號**(見第 10 節)。
- **滾動回測**:用嚴格的 point-in-time (無未來函數) 驗證這套評級/排序在歷史上有沒有效。

三種使用方式:命令列 (`main.py`)、網頁 (`app.py`,Streamlit,共 10 個分頁)、以及回測 (`tests/run_backtest.py`)。

## 2. 快速開始

1. 準備 FinMind Token(見第 3 節)。本機自用可放進根目錄 `.env`:`FINMIND_TOKEN=你的token`;網頁公開站則在左側欄貼自己的 token。
2. 安裝套件:`pip install -r requirements`(或至少 pandas、openpyxl;網頁再加 `streamlit`;快取再加 `pyarrow duckdb`)。
3. 跑跑看:
   - 個股 (命令列):`python main.py 2330`
   - 個股 (網頁):`pip install streamlit` 後 `streamlit run app.py`
   - 排行:`python main.py 2330 2454 2317`
   - 回測:`python tests\run_backtest.py --cache`

## 3. 取得 FinMind API Token

「個股分析」與「多檔排行」會即時向 **FinMind**(台股開源金融資料 API)抓最新資料,需要一組**你自己的** token。免費、用 Email 註冊就有,一分鐘內可拿到:

1. 開啟官網 👉 **https://finmindtrade.com/**
2. 點右上角 **登入 / 註冊**,用 Email + 密碼註冊,到信箱點驗證信完成啟用。
3. 登入後進入**會員中心** 👉 **https://finmindtrade.com/analysis/#/account/user**
4. 找到 **API Token(api_token 金鑰)**,整串複製起來。
5. 貼到你要用的地方:
   - **本機自用**:寫進專案根目錄 `.env` 的 `FINMIND_TOKEN=…`。
   - **網頁公開站**:貼到左側欄「你的 FinMind API token」輸入框(只存在你這次的瀏覽階段、算你自己的額度、不共用、不寫入伺服器)。

**額度(大致)**:不貼 token 的匿名模式每小時額度極低、即時查詢常失敗;**免費註冊會員每小時約 600 次**,個人研究綽綽有餘;贊助 / Sponsor 方案上限更高。詳見官網,登入說明:https://finmind.github.io/login/。

## 4. 每檔用多少 API?一次查幾檔剛好?

**本機版已去 FinMind 化(2026-07-16 起)**:個股分析的各資料集(股價、本益比、月營收、三大財報、法人買賣超、融資融券、股數/外資持股)全部改走本機資料(TEJ 歷史種子+每日官方快照收集器,見第 9 節),**單檔分析 0 API**——整個程序只剩大盤 TAIEX(每次執行 1 支)與產業別(每 30 天 1 支)。某項本機資料過期時(例如電腦多日未開機、收集器沒跑到),該資料集會**自動退回 FinMind**,回補後自動歸零。

以下用量估算適用**雲端公開站訪客**(雲端沒有本機快取,用自己的 token 即時抓)、或本機資料過期退回 FinMind 的情況:每分析一檔全新股票,大約向 FinMind 送出 **9 支請求**(股價、法人買賣超、流通股數、融資融券、月營收、本益比河流圖、損益表、資產負債表、現金流量表)。

但系統有**本機快取**:同一檔股票**當天再查幾乎不再耗 API**(直接讀快取),只有第一次抓、或加了 `--refresh` /勾了網頁「刷新最新資料」時才會實際打 API。所以真正吃額度的是「這一小時內第一次分析的股票檔數」。

以免費會員每小時約 600 次估算,600 ÷ 9 ≈ **一小時可全新分析約 60 檔**。建議:

- **個股分析**:一次 1～5 檔最順手。
- **多檔排行**:逐檔即時打 API,建議**一次 20 檔以內**、盡量不超過 **30 檔**(30 檔全新 ≈ 270 次)。
- **想一次掃上百檔** → 用「綜合分選股」(第 8 節):0 API、免 token、瞬間出。

若短時間連續分析大量沒查過的新股票而抓不到資料,通常是撞到每小時上限,**等一小時額度重置**即可,或先用綜合分選股頂著。

## 5. 三種模式怎麼選(最重要)

模式 (保守/平衡/積極) **不設定持有天數**,它決定的是「分數由哪些訊號主導、門檻多嚴」。因為動能/籌碼訊號衰退得快 (短線)、基本面/估值走得慢 (長線),所以挑**跟你實際打算持有多久相符**的模式:

| 你的情況 | 模式 | 說明 |
|---|---|---|
| 新手 / 不確定 / 中線波段 (數週~數月) | **平衡** (預設) | 以基本面+技術為核心,最穩、最不被單一雜訊帶走 |
| 長線 / 存股 (數季以上) | **保守** | 重基本面品質與估值、門檻高,選得少但扎實,抱得住 |
| 短線 (數天~數週,會主動停損) | **積極** | 重動能與籌碼點火、門檻低,抓正在噴的股;雜訊與交易成本最高 |

> 誠實提醒:回測顯示「積極」那套動能主導的權重,樣本外排序力最弱 (動能因子的 Rank IC 是負的),
> 而且短線是最難、成本最高的玩法。**多數人(包含很多自以為做短線的人)用「平衡」會更好**;
> 「積極」比較適合知道自己在做什麼、會嚴設停損的人。

命令列切換:`python main.py 2330 --mode conservative`(或 `-m c/b/a`)。網頁在左側直接點選。

## 6. 四個評級是什麼意思(常被誤解)

系統有**兩條並行的買進軌道**,不是同一件事的強弱:

- **強勢買進 = 順勢動能軌**:正在領漲的主流股 —— 均線多頭排列、動能強、法人主力狂吸,
  這時系統會**特赦**「太貴/RSI 高/乖離大」的反對票,因為成長跟籌碼撐得住。屬於「騎強勢的馬」。
- **強烈推薦 = 價值/品質軌**:便宜或合理的好公司 —— 估值偏低、基本面扎實、沒過熱、沒追高。
  屬於「用好價格買好公司」,常是回檔/打底時的進場。
- **觀望追蹤**:訊號不足或有疑慮 (例如獲利品質存疑、籌碼不足),先追蹤、不急。
- **謹慎避開**:基本面或技術面不佳,避開。

兩個重點:

1. **「強勢買進」不代表現在就要買。** 評級是對「當前狀態」的分類。很多強勢買進的股票,
   買點提示會明白寫「現價追高,回檔守穩支撐再進較穩」。**評級看值不值得擁有,買點提示看該在什麼價位進場**,兩段一起讀。
2. **排序上強勢買進(3) 高於強烈推薦(2),但不代表報酬一定更高**,只是系統對該 setup 的信心層級。
   一個給順勢派、一個給價值派。

## 7. 怎麼讀個股分析輸出

一份個股報告會有:

- **綜合評分 + 評級**:四維度加權後的總分,與最終評級。
- **分項得分**:技術 / 動能 / 籌碼 / 估值 / 基本面(0~100)。看是哪個維度撐起或拖累總分。
- **基本面評價 / 動態趨勢 / 估值狀態 / 獲利品質**:白話標籤。
- **系統建議 + 買點提示**:含「大戶成本區 / 支撐 / 壓力」與「動態防守參考(停損)」。
  現價遠高於成本區時會標「早期累積區(僅供參考)」,並改以「現價下方最近高量支撐」為可操作成本區。
- **月營收即時動能註記**:季報有約 45 天公告時差,當月營收動能明顯轉強時,會提示「以月營收為即時依據」。

## 8. 綜合分選股怎麼用(海選整份名單)

這頁跟「個股分析 / 多檔排行」最大的差別:那兩頁是**即時抓最新資料、一檔一檔算**;這頁是讀一份**事先算好的分數快照**,把**整份自選名單**一次拿來比高下、由高到低排名。所以它 **0 API、免 token、瞬間出結果**,最適合「先海選一輪、再挑幾檔回個股分析看即時細節」。

**操作三步驟**

1. 左側選好**策略模式**(三個模式各一套權重、各一套分數,換模式排名就會變)。
2. 設四個篩選條件:**綜合分下限**(預設=該模式門檻)、**資料信心下限**、**顯示檔數**、**限定評級**(不選=全部)。
3. 看排名表,可**下載 CSV**;想深入某幾檔,把代號貼回「個股分析」看即時細節。

**欄位怎麼看**

- **綜合分**:五維(基本面、估值、技術、動能、籌碼)加權後的總分;權重依模式不同。
- **百分位**:這檔綜合分在**這份名單裡**的橫斷面排名(0～100,越高代表在名單中越前面)。
- **五維分數 / 估值狀態 / 信心**:各面向細分與資料完整度(信心低=部分資料缺漏,分數參考性打折)。
- **基準日 (as_of)**:這批分數是「哪一天」算出來的 —— 它是**快照、不是當下即時價**。

**重要:資料是快照,不是即時。** 想要最新即時的單檔狀態,回「個股分析」用你的 token 重抓。

### 8-1. 自選名單由你控制(watchlist.txt)

綜合分選股比的「整份名單」= 專案根目錄的 **`watchlist.txt`**,**完全由你自己維護**:

- **一行一檔**,只放代號即可(例:`2330`);代號後可加名稱/註解(例:`2330   # 台積電`)。
- **空白行、或 `#` 開頭整行**會略過 —— 可拿來分群、寫筆記。
- **重複代號自動去重**;**刪掉或清空整個檔案**則自動回退內建的 45 檔分散化測試池。

改完名單後要讓排名反映新名單,需**重算分數**:

```
python build_cache.py --build-scores          # 重算三個模式的綜合分 (0 API,讀本機原始快取)
```

- **本機/自架**:重算後回網頁按分頁上的「↻ 重新載入快取」即可看到新名單。
- **雲端部署站 (Streamlit Cloud)**:線上的綜合分選股讀的是 repo 內已提交的 `cloud_cache/Scores` 快照。
  所以**光改 `watchlist.txt` 不會馬上反映到線上** —— 需在本機重算後,把快照 commit / push 上去
  (執行 `python deploy_scores.py --rebuild-scores`,或雙擊 `update_and_push.bat`),Streamlit 才會重部署成新名單。

> 一句話:名單是你控制的;線上版要「重算 + 上傳」後才會更新。

## 9. 全市場掃描(0 API 海選 1,900+ 檔,watchlist 之外找新標的)

「綜合分選股」排的是你 watchlist 裡的股票;**全市場掃描**則是從上市+上櫃約 1,900 檔
普通股裡自動海選,**完全不用 FinMind API**(資料來自 TWSE/TPEx 官方開放端點+TEJ 歷史種子)。

**每天自動發生的事**(排程 `Market_SnapshotCollector`,平日 17:30 收當天資料):

```
官方快照(價格/PE/三大法人) → 三層漏斗粗篩 → 五因子聯集 shortlist → 每日摘要
   1,900+ 檔                    ~920 檔           ~480 檔          digest_{日期}.md
```

- **粗篩三層**:L0 因子可評估(虧損股 PE 空白出局)→ L1 可投資性(20日均成交額≥1,000萬+
  上市滿年)→ L2 陷阱排除(極端便宜+營收衰退的「價值陷阱」股,21 年歷史驗證)。
- **五因子聯集**:產業內估值位階/20日動能/法人買超/52週高接近度(突破)/營收加速度,
  任一因子進池內前 15% 即入榜,附 composite 綜合排序。

**怎麼看結果**(三選一):

1. **網頁**:`streamlit run app.py` → 「🌐 全市場掃描」分頁——regime 警示、來源臂/
   連續在榜/產業篩選器、今日新進前 50。雲端版也有(每晚 20:30 隨 scores 一起上雲)。
2. **每日摘要**:開 `outputs\universe_pool\digest_{日期}.md`——新進前 50、連續在榜
   亮點、每檔的「來源臂」(憑哪些因子進榜;**多臂交集股通常是最值得先看的**)。
3. **完整名單**:`outputs\universe_pool\shortlist_{日期}.csv`。

**重要心法**:shortlist 是**分流參考不是投組**——它負責把 1,900 檔縮到值得你花時間看的
範圍,最終判斷仍是你的深度分析(把感興趣的加進 `watchlist.txt` 走完整四維評分)。
空頭時段(頁面會掛 ⚠️ 警示)這份名單的歷史超額為負,參考性降低。

## 10. 網頁其他分頁:市場燈號 / 定期定額 / 雙確認精選 / 實戰演練 / 法人流向

這五個分頁是把「怎麼實際運用這套系統」做成可操作的工具,全部 **0 API、免 token**、讀本機/雲端已算好的資料。

### 10-1. 🚦 市場燈號 —— 現在該持有幾成

回答「大盤現在偏多還偏空、我該滿倉還是先降部位」。**它不預測漲跌**,只用等權大盤與 50/100/200 日均線的相對位置,
輸出一個**建議曝險比例**:100%(站上全部均線)/ 67% / 33% / 0%(全部跌破)。為了不被單日雜訊騙,採**對稱確認 3 天**
的遲滯設計(要連 3 天站穩才加碼、跌破則較快減碼),頁面會標「遲滯確認中」。

- **怎麼用**:當紅綠燈看——燈號轉弱(曝險下降)時,考慮把主動選股的部位降下來、或把「空頭轉現金」的規則打開;燈號回強再加回。
- **怎麼來的**:這正是回測裡讓策略「空頭少賠、淨贏 0050」的那條風控規則(見開發日誌 §25),搬到網頁給你即時看。
- **限制**:它是**趨勢/波動的反應器,不是方向的預測器**。碎波盤(像 2022 那種假反彈陰跌)本來就是它最難處理的環境。

### 10-2. 💰 定期定額試算 —— 你實際會拿到幾 %(MWRR)

輸入**每月投入金額**與**起始年份**,並排比較「本策略(綜合分前 20% + 風控)」與「0050 買進持有」在定期定額下的
期末金額、倍數、**MWRR(內部報酬率,你實際到手的年化)** 與最大回撤,並畫出兩條累積曲線。用的是 2005–2026 的**真實含息**序列。

- **誠實發現**:在定期定額下,**每個起始年 0050 的 MWRR 都賺得比策略多**(定期定額本身會自動逢低加碼,而 0050 會自我修復);
  但**策略的回撤大約只有 0050 的一半**(空頭時策略減碼躲跌,代價是也躲掉了「趁跌撿便宜」)。
- **一句話**:想追求長期報酬最大 → 純 0050 定期定額;想睡得著、回撤小 → 才考慮加策略。這頁就是讓你親眼比一次。
- **名詞**:報酬率有好幾種(ROI/CAGR/IRR/TWRR/MWRR),**它們都只講報酬、不含風險**;風險要另看夏普/回撤。有定期扣款時,
  看**MWRR**(把扣款時點權重算進去的個人真實報酬)最貼近你的實際體感。

### 10-3. ✨ 雙確認精選 —— 兩套邏輯同時看好的交集

把兩種相反性格的排名疊在一起取交集:**c2(價值/反追高)前 20%** ∩ **綜合分(品質/順動能)前 20%**。
落在交集裡的股票,等於「便宜/沒過熱」與「基本面強/有動能」同時成立,是系統信心最高的一批。頁面**直接附上這籃對
含息 0050 的全循環回測證據**——讓你看到它贏在哪(早年弱多頭段、空頭防禦)、輸在哪(2019-21 大牛與 2022 碎波),
而不是只丟一份沒來由的名單。

### 10-4. 📋 實戰演練 —— 把名單當 30 天模擬單練紀律

這頁的用途**不是證明賺不賺錢**(單一小批 8 檔、20 天的訊噪比太低),而是練**操作迴圈**:凍結一份選股計畫卡
(買進時間 T+1 開盤整批、價格區間、賣出時點),照它下模擬單、**回填實際成交價**,系統每日自動追蹤你這批 vs 0050、
算滑價(實際成交 vs 理論開盤價),到第 20 個交易日做三方對帳。成本以**元大零股 6 折**(買 0.0855%/賣 0.3855%)如實計。

- **重點紀律**:預測一旦凍結就**不可事後改**;成交只回填、不修改計畫。這是把「紙上談兵」變成「照表操課」的地方。

### 10-5. 🏭 法人流向 —— 錢每天往哪個產業流

把全市場三大法人的**每日淨買股數 × 收盤價**換成金額,再依 TEJ 產業別加總,就得到「各產業每日淨流入」。
資料歷史來自本機 TEJ 種子(2004 起)、最新一段由證交所 T86 ＋ 櫃買 3insti **每日 17:30 自動接上**,全程 0 API。

> **⚠️ 先講定位:這是描述圖,不是買賣訊號。** 本專案的實測(法人賣轉買回測)結論是
> **「賣轉買 = 反指標」**,只有**持續買**才有微弱邊際。所以請把這頁當「看懂盤面資金結構」用,
> **不要**看到某產業被大買就照著追。

**四個選項怎麼調**:

- **產業層級**:子產業(最細,散裝航運/貨櫃輪這種粒度,約 252 類)/ 產業 / 上市產業(最粗,35 類)。想看大方向用粗的,想找主題用細的。
- **法人別**:外資+投信 / 外資 / 投信。外資量體大、動得慢;投信量小但常是台股主動作多的先行者。
- **期間**:近 20 / 60 / 120 / 250 日 / 全部。決定「播放」有幾幀、以及「期間累計」算多長。
- **量綱**:這頁最重要的一個開關 ——
  - **億元**:絕對金額。缺點是**權值股會吃掉整張圖**(晶圓代工一天可以 −1121 億,其他產業全被壓成細絲)。
  - **占成交額 %**:淨流入 ÷ 該產業同期成交額。把大小產業拉到**同一把尺**上比,小產業的「相對吸金強度」才看得見。
    例:全期累計用「億元」看,賣超榜由晶圓代工 −10,000 億獨佔;換成「%」,它只是排在賣方尾段,買超頭部變成金融控股/電信及IDC/本國銀行。

**三種檢視**:

- **單日掃描(可移動)**:某一天的產業淨流入排行(紅=買、綠=賣,台股慣例)。按 **▶ 播放連續天數**會逐日推進,
  看得到資金在產業間輪動的過程;也可以拖滑桿手動掃到任何一天。期間拉太長時會自動抽幀(畫面會告訴你「每 N 日抽 1 幀」)。
- **期間累計**:整段期間誰累積吸金最多 / 失血最多,下面再附**前 5 名的累計趨勢線** —— 用來分辨
  「**持續吸金**」和「**單日爆量**」:一路往上爬的是前者,一根跳上去然後平掉的是後者。
- **產業地圖(Treemap)**:**方塊大小 = 成交額**(這個產業有多少資金在裡面跑)、**方塊顏色 = 法人淨流入**
  (紅=買超、綠=賣超)。一眼看完「台股的錢集中在哪幾塊、其中哪幾塊法人在買」,類似盤後常見的產業熱圖。
  可切「單日 / 期間累計」。

**什麼時候用哪一種**:想知道**精確排名與數字**用長條圖(前兩種)——長度是人眼判讀最準的通道;
想知道**整體版圖與資金分布**用產業地圖——但面積的判讀精度天生比長度差,所以它是拿來「看形勢」的,
不是拿來比大小的。兩者是互補,不是誰取代誰。

> Treemap 只畫成交額最大的幾個產業(跟著「顯示產業數」滑桿走),圖下方會**明白告訴你畫了幾個、
> 占全部產業成交額幾 %、沒畫的是哪些**(排名之後的 / 薄量被剔除的),不會默默省略。方塊太小時不標字,滑上去看 tooltip。

**怎麼讀這些圖(視覺語言)**:

- **顏色 = 方向**:**紅 = 買超、綠 = 賣超**(台股慣例,與歐美相反)。顏色只負責告訴你方向,不負責告訴你大小。
- **長度 = 數值**:長條有多長就是流入多少,這是最準的一條線索。
- **透明度 = 金額大小**:小額會淡出、大額才會全滿。用意是壓掉中段一堆短長條的干擾,
  讓真正的大額資金一眼跳出來。淡的不是「沒資料」,是「相對小」。
- **數字直接標在長條尾端**,不必去對 X 軸或把滑鼠移上去。
- **由上而下 = 買最多 → 中間 → 賣最多**,長條圖與成分股圖都是這個順序。
- **Treemap 的色階是三段式**:0 附近會退到接近背景色(不搶注意力)、兩端才拉滿飽和 —— 「極端值亮如發光、中間值暗如背景」。

**「配色」選項**:網站會跟著你**瀏覽器/系統的深淺色模式**自動切換介面主題,所以配色也有兩組:
**淺色底**(白底用,零軸退向近白)與**深色底(霓虹)**(深色模式用,`#FF1744`買/`#00E676`賣 高彩度)。
系統會自動幫你選,選錯了自己切一下就好 —— **拿深色底那組配白底會刺眼、拿淺色底配深色底會偏灰**。

**下鑽成分股**:選一個產業展開,看是**哪幾檔**撐起這條資金流。貼代號回「個股分析」就能看那檔的四維度深評。

**三個要知道的限制**:

- **產業分類是「現在的」分類表套到歷史**,已下市的股票對不到產業會被丟掉 → 有存活者偏誤。看盤面可以,**別拿它當回測結論**。
- **占比口徑在指數調整日會爆表**(整個族群同一天 40–60% 都可能)。數字是真的,但那多半是被動資金的機械式買盤,不是主動看多。
- **薄量產業已被剔除**(占比模式下成交額 < 5 億/日),否則小產業會做出 ±100% 的假極端。
- **下鑽的成分股資料只留最近 250 個交易日**(全歷史太大)。若你把期間拉得更長,畫面會明白告訴你
  「下鑽是 X～Y 的累計,比上方主圖短」,不會讓兩個數字默默對不起來。

**資料怎麼更新**:這頁的快照**不在每日排程裡**,要更新資料日請手動跑:

```
python scripts/build_industry_flow.py               # 預設近 3 年
python scripts/build_industry_flow.py --start 2004-01-01   # 全歷史(約 33 MB,本機看就好、別上傳)
```

## 13. 每日自動更新(免手動維護快取)

不想每天手動跑 `build_cache.py` 的話,可以把它交給 Windows 工作排程,**平日 20:30(收盤後籌碼資料已出)自動跑**:

1. 雙擊 `scripts\register_daily_task.bat`(或以系統管理員身分執行 `register_daily_task.ps1`),
   一鍵註冊排程 `FinMind_DailyUpdate`。
2. 之後每個平日 20:30 會自動執行 `scripts\daily_auto_update.bat`:
   `build_cache.py`(增量建庫 + 刷新 scores)→ `deploy_scores.py`(快照 → commit → push)。
3. 錯過時段(電腦關機/休眠)會自動補跑;單次執行超過 2 小時會強制結束,避免卡死排程。
4. 執行紀錄在 `outputs\logs\`(保留 30 天),想確認有沒有正常跑可以直接看最新一份 log。
5. **失敗保護**:任一步 build 失敗就停止、不會把壞快照推上雲端。

想重新註冊或改時間,重新雙擊 `scripts\register_daily_task.bat` 即可覆蓋舊排程。

## 14. 常見問題 / 注意事項

- **這是投資建議嗎?** 不是。它是篩選/研究輔助,決策與風險由你自負。
- **這套能贏 0050(大盤)嗎?** 誠實說:拿含息還原的 0050 買進持有當基準,選股在整個市場循環約略貼平至微贏,**不是穩贏**;
  它的優勢主要在**空頭少賠(風控補回撤)**。想穩穩參與長期報酬,核心還是定期定額 0050,個股當練功/求穩的衛星部位。
- **市場燈號能預測漲跌嗎?** 不能。它只反應趨勢/波動、告訴你「該持有幾成」,不預測方向;碎波盤(假反彈陰跌)是它最弱的環境。
- **貼了 token 還是抓不到?** 確認整串有複製到、帳號 Email 已完成驗證;短時間查太多檔可能撞每小時上限,等一小時額度重置。
- **不想註冊 FinMind 可以用嗎?** 可以用「綜合分選股」—— 0 API、免 token,只是資料是上次建快取的基準日、不是即時。
- **顯示的價格跟券商不一樣?** 可能是還原股價 (配息調整);下單以券商報價為準。
- **看到強勢買進就能追?** 不行。先看買點提示,若寫「追高」就等回檔;並自設停損與部位大小。
- **為什麼很少出現買進評級?** 這是「沒好貨就空手」的特性,不是壞事;想放寬可用平衡模式或擴大股票池 (改 `watchlist.txt`)。
- **資料可能有幾天延遲?** 快取為省 API 預設 2 天內視為新鮮,要最新用 `--refresh`。
