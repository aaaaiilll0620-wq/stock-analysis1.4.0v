## 2. legacy `0.1585%` —— **provenance 不足,不帶入 B0**

| 拆解 | 判定 |
|---|---|
| `SELL − BUY = 0.003` | 與證交稅 0.3% 相符 |
| `BUY = 0.001585` | 標示為「手續費(依使用者實際券商費率)」 |
| `0.1585% − 0.1425% = 0.016%` | **無任何文件記載其構成** |

**判定:`UNRESOLVED_PROVENANCE`。** 無法確認 `0.1585%` 是「某券商實際費率」、「手續費 + 隱含滑價的混合值」、還是其他。**依 P6 裁決,該 0.016% 殘差記為 unresolved provenance,不進 B0。**

**注意本判定的強度:** 這**不是**「該數值錯誤」的認定 —— 它可能完全正確,只是無從查證。B0 不採用的理由是**來源不可追溯**,不是**數值被證偽**。

## 3. Frozen B0 成本模型(P1–P6 已裁決)

### 3.1 三分離記帳(強制)

```
explicit_fee(V)   = max( MIN_FEE , V × commission_rate )      # 買賣皆有
transaction_tax(V)= V × 0.3%                                   # 僅賣出
impact(V, i, t)   = V × k × σ20D(i,t) × sqrt( V / ADV20(i,t) ) # 買賣皆有

total = explicit_fee + transaction_tax + impact
```

**三者必須分欄記帳,不得合併成單一比例。** 理由:三者的不確定性來源完全不同 —— `explicit_fee` 是**已宣告的券商政策**、`transaction_tax` 是**外部稅制**、`impact` 是**外部先驗估計**。合併後將無法區分「成本假設錯」與「策略錯」。

### 3.2 凍結參數

| 符號 | 值 | 性質 | 依據 |
|---|---|---|---|
| `commission_rate` | **0.1425%** | **B0 reference commission rate**;`d = 1.0`,**不假設任何券商折扣** | P1 |
| `MIN_FEE` | **NT$20** | **B0 reference broker policy,非法規**;**整股與零股一致** | P2 |
| `tax_rate` | **0.3%**(僅賣出) | 證券交易稅 | 外部稅制 |
| `σ20D(i,t)` | **trailing 20 交易日 log return 標準差**,**PIT**、**未年化** | 20D horizon 刻意重用 `ADV20` 的量尺 | P3 |
| `k` | **1.0** | **canonical order-one external-prior reference**,**不宣稱為台股估計值** | P4 |
| multi-day execution | 每一交易日視為**獨立 child order**,逐日以當日 `σ20D`、`ADV20`、**實際成交金額 V** 計 impact 後**加總**;**不引入 decay 參數** | | P5 |
| 其他規費 | **不新增**(交割費等未經可靠來源證實者一律不納) | | P6 |

**`d = 1.0` 的意義:** 不假設折扣是**保守方向**的選擇,且**零自由參數** —— 一旦允許 `d` 可調,它就會變成另一個可被結果驅動的旋鈕。

## 4. 顯性成本的非線性(算術不受 §0 更正影響)

`MIN_FEE = NT$20` 使有效費率隨訂單金額急升。臨界金額:

```
V* = MIN_FEE ÷ commission_rate = 20 ÷ 0.001425 ≈ NT$14,035
```

| 訂單金額 V | 應收 | 實收 | **有效費率** |
|---:|---:|---:|---:|
| 100,000(完整 5% 部位 @ C_ref) | 142.5 | 142.5 | 0.1425% |
| 14,035 | 20.0 | 20.0 | 0.1425%(**臨界**) |
| 5,000 | 7.1 | **20.0** | **0.400%** |
| 2,000 | 2.9 | **20.0** | **1.000%** |
| 1,000 | 1.4 | **20.0** | **2.000%** |

**B-06/B-12 剛啟用的三件事系統性製造小額訂單:**
1. **odd-lot** —— 部位不再被整張捨去,delta 可為任意股數;
2. **delta 再平衡** —— `compute_order_intent` 對續留標的只交易 `delta = target − current`,漂移一個月後常僅為目標部位的個位數百分比;
3. **`pending_exit` 殘額** —— 多日出場的最後一日殘額可能很小,且依 P5 每日皆為獨立 child order。

**⇒ 成本必須逐筆訂單計算,逐期比例近似在結構上不可行,且只會低估。** 這一項在 B-06/B-12 CLOSED 之前不可能被發現。

## 5. 市場衝擊的量級(成本模型輸入特徵化,**非策略評估**)

依 P3/P4 定案值,對凍結窗口內 `ADV20 ≥ NT$10,000,000` 的標的計算 `σ20D` 分佈(124,201 個股票-決策日觀測):

| 分位 | `σ20D`(日,未年化) | **cap 處單邊 impact = k × σ20D × √1%** |
|---|---|---|
| p25 | 1.46% | **0.146%** |
| **p50** | **2.17%** | **0.217%** |
| p75 | 3.12% | **0.312%** |
| p90 | 4.15% | **0.415%** |

**對照 `commission_rate = 0.1425%`。**

**結構性結論(不是績效主張):**

> **在 1% cap 處,median model-implied impact rate(0.217%)> reference commission rate(0.1425%)。**

**措辭限定(刻意):** 上句只陳述**本模型在 cap 處的隱含衝擊率中位數**與**參考手續費率**的大小關係。它**不**主張現行模型「低估了多少總成本」,也**不**是對任何策略績效的陳述 —— 兩者都需要 B0 回測,而回測未執行且未授權。

**動態 ADV floor 的一個未被預期的性質:** 因 `Q/ADV ≤ X = 1%`,故 `√(Q/ADV) ≤ 0.1`,**entry 的單邊衝擊被政策直接封頂於 `0.1 × σ20D`**。B-06 的 R1 裁決在鎖住容量的同時,也把衝擊成本上界鎖住了。

**⚠ 本節僅特徵化成本模型的輸入,未計算任何策略報酬、未產生任何選股名單。**
