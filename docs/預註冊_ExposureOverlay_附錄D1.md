**不是**門檻或規格的變更。
**裁定者**:Codex(2026-07-31),回應 runner 實作時提出的 (D1) 待確認項。

## 1. 為什麼需要這份附錄

主預註冊 §3-A-D 定義了:
- 本體 A 的**日報酬** `r_A(d)`(open(d)→open(d+1) 價格 + 均勻加性股利 δ),以及
- 月度**加性**對帳 `(價格連乘−1)·100 + Σδ = fwd_x`(凍結門檻)。

但**沒有逐字規定**「選股換手成本 `turn·(FEE_RT+slip)` 落在該月的哪一個日段」。
月度**加性**總額不受落點影響(成本是每月一筆的加性項),但**日 NAV 複利路徑**會受影響,
而 HO1/HO4a 的 `|MDD| ≤ 40%` 是在**日 NAV** 上量的 → **落點必須在跑數字之前定死**,否則就是
「看到數字再決定成本擺哪天」,那會使 MDD 成為可事後調整的量。

---

## 2. 裁定(凍結)—— 兩項:**落點** + **套用算術**

### 2-1 落點:`COST_PLACEMENT = "entry_day"`

> 選股換手成本 `turn·(FEE_RT + slip)` 於**每月新持股在 `open(訊號日+1)` 建倉的
> 第一個 open→open 日段**扣除。**初始建倉(序列第一個月)依同一規則處理**
> (該月 `turn = 1.0`,即 100% 建倉,成本同樣落在其第一個日段)。

**理由**:成本在真實執行上發生於**下單成交當下**,即建倉日;把它攤到月中或月末都不對應任何
真實交易行為。`entry_day` 是唯一與 `fwd_x` 進場慣例(`open(訊號日+1)`)一致的落點。

### 2-2 套用算術:`COST_ARITHMETIC = "additive_return"`(2026-07-31 補鎖)

> **對該日段的「報酬」做加性扣除**:
> ```
> r_day := r_day − turn·(FEE_RT + slip)
> ```
> **不採 NAV 乘法**(`nav *= (1 − cost/100)`)。

**理由**:與 **frozen 官方月度定義 `r_A(t) = gross − turnover_cost` 的加性形式一致**。
§8-1b 的凍結對帳門檻(加性分解 = `fwd_x`)正是建立在這個加性語意上;若改用 NAV 乘法,
會引入 `−cost × gross` 的二階交叉項,使日路徑與官方月度定義**不同調**,並讓日→月的加性
對帳出現本不該有的殘差。

**兩項合起來的唯一合法組合**:`entry_day` + `additive_return`。
runner 以 `_apply_sel_cost()` 為**單一事實來源**(向量路徑 `_build`、滑價變體 `with_slip`、
第二路徑 `ledger_body_daily` 三處皆呼叫),並由 `_assert_frozen()` fail-closed 鎖定。

**唯一被明確化的兩件事**(此前未逐字規定):
1. 成本在**月內的日期落點** → `entry_day`;
2. 成本的**套用算術** → `additive_return`(對報酬加性扣除,非 NAV 乘法)。

兩者都只影響**日內路徑的表述方式**,不改變任何月度量、門檻或規格。
反而是 `additive_return` **強化**了與 frozen 月度定義的一致性(見 §2-2)。

## 4. 已知的二階效應(誠實揭露)

- 落點**會**以二階量影響**日 NAV 複利路徑**,因而影響日 MDD。這正是必須 pre-run 凍結的原因。
- **與主預註冊 §3-A-D-💰 已公布數字的關係(已由 §2-2 裁定收斂)**:該節公布的
  「本體 A OSS 日 NAV MDD **−33.72%**」是以**乘法式**(`×(1−cost/100)` 套用於該月路徑)計算的,
  落點同為建倉日。本案現**鎖定加性**(`dr[0] −= cost`)。兩者落點相同、算術不同,差異為
  **二階項 `−cost×gross`**(cost 每月約 0.4–0.8%,故量級 ~1e-3 pp 級)。
  → **後果**:runner 產出的本體 A 日 MDD 可能與已公布的 −33.72% 有**極小**差異。
  這是**已知且已揭露**的,**不得**因此回頭修改 §3-A-D-💰 的凍結數字(那是凍結內容),
  也**不得**反過來改回乘法以「對上」舊數字 —— 加性才是與官方月度定義同調的那一個(§2-2)。
- **252 日年化**(主預註冊 §3-A-D):實際交易日約 247/年,以 252 年化會使 CAGR 略為高估
  (20% 量級約 +0.4pp)。**這是 frozen 規則,本附錄不修改,僅保留揭露**;§7 填寫時須一併載明。
- 本附錄凍結時,**尚未**以任一落點計算過 A×C 的 OOS 結果。
