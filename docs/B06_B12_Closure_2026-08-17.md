## 4. B-06 ↔ B-12 循環定義的打破規則

### 4.1 循環

- B-06:ADV 門檻 = `單檔部位 ÷ X`,而 單檔部位 = `C / N`
- B-12:`N` 由 capacity 決定

⇒ **N 依賴門檻,門檻依賴 N。**

### 4.2 建議的打破規則(給定 A1 `C` 與 A2 `X` 後,零額外參數)

```
ADV_floor(N) = C / (N × X)
Eligible(N)  = { i : ADV20_i ≥ ADV_floor(N) }
N* = 滿足 |Eligible(N)| ≥ N 的 N
```

**這個定點是良定義的**:N 增大 → `ADV_floor` 遞減 → `|Eligible|` 單調不減,因此可行 N 構成一個區間,直接掃描 N 即得端點。

**三個關鍵性質:**
1. **不依賴任何分數** —— `Eligible` 用的是全母體的 ADV,不是被選中的名單。**因此不構成選股,也不需要看任何結果。**
2. **零額外自由參數** —— 給定 `C`、`X` 後完全機械。
3. 取區間的哪一端(最大 N / 最小 N)是 **A6**,屬政策。

### 4.3 尚未被此規則涵蓋的一項

張數約束 `C / N ≥ LOT_SIZE × price_i` **依標的價格而異**,無法在 N 決定階段一併滿足 —— 高價股在小 `C` 下必然買不到一張。這正是 `TOP_N=15` 濃縮想解決、卻被 H4 滑價否決的那個真問題(`l4a_decision.py:47-53` 明文記載「問題還在,只是解法被否定,不得繞過去」)。

**B0 的處置取決於 A5**:若假設零股可成交,問題消失;若不可,必須明文記錄每期因此落空的部位數(可量化,且屬涵蓋率診斷不屬績效)。
